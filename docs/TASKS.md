# 任务注册与调试台

任务台只接受服务端已经注册的任务 ID，不接受网页提交的可执行文件路径、固定参数或环境变量。任务由可信脚本执行，不是操作系统沙箱；管理员需要检查脚本本身的读写行为。

在服务配置目录放置 `tasks.json`，重启服务加载。注册文件独立于媒体库与主库状态。服务自带漫画封箱与索引更新任务，manga.pack/manga.index 是保留标识，不能重复注册；操作说明见 features/manga/README.md（预览包 MANGA_TASKS.md）。下面是可直接试运行的 uv 版本检查（需要系统已有 uv），不修改媒体：

```json
[
  {
    "id": "uv.version",
    "name": "检查 uv 版本",
    "category": "media_library/docs",
    "write": false,
    "executable": "uv",
    "args": ["--version"],
    "parameters": []
  }
]
```

进入 Web 任务台，选择该任务、资源库及 docs 内的现存目录，启动后查看日志。目录留空表示分类根目录。此检查仅用于验证注册与执行流程；业务爬虫及文本构建脚本还需分别实现/注册，项目没有把版本检查当作这些功能。

注册字段：

| 字段 | 含义 |
|---|---|
| id / name | 唯一任务标识和显示名称 |
| category | 库内分类，如 media_library/manga；不能跨分类访问所选目录 |
| write | 声明是否写入；写任务拒绝只读库，与重叠目录的读/写任务互斥 |
| executable | 已安装程序名，或服务配置目录内的相对可执行路径，也可使用配置的绝对路径 |
| args | 受信任的固定参数数组，不经 shell；其中 `{config_dir}` 展开为配置目录 |
| parameters | 按数组顺序追加的表单参数；每项 name、label、required，值原样作为单个参数 |
| env | 服务端环境变量，如站点凭证；不会进入任务目录、HTTP 目录或任务状态 JSON |

运行目录与环境变量 `OMNIHUB_TASK_DIR` 都是校验后的实际资源目录。Python 任务使用 uv，例如固定参数 `run --offline --no-project --no-python-downloads {config_dir}/features/manga/scripts/pack.py`（JSON 中每个参数单独一项）；文件需先放到对应位置，不会自动安装脚本、Python 或依赖。不要把秘密放在 args 或表单值中，使用 env；类 Unix 上含 env 的注册文件必须设置为仅当前用户可读写，例如 `chmod 600 tasks.json`。脚本仍需避免把凭证打印到日志。

注册文件最多 64KiB/32 项，每项最多 16 个表单参数；单值 1024 字节，未知字段、缺少必填值、NUL、重复标识和无效可执行文件都会被拒绝。注册错误只停用任务模块，账号、媒体等模块继续工作，任务台显示错误；修复配置后重启。没有后台轮询注册文件。

目录锁根据实际目录路径比较父子关系，不以任务 ID 代替：同目录/父子目录只要有写任务就互斥，两个声明为读的任务可并行，不同目录可并行。锁持续到真实进程、后代与日志管道清理完成；索引/主库配置迁移也会等待活动任务停止。该锁协调服务托管任务，不协调用户在外部直接运行的程序。

任务历史最多 16 项，服务每项保留最近 256 行；服务重启后不恢复任务。Web 最多保留 512 行、显示最近 128 条匹配项，每 250ms 合并刷新。暂停只暂停显示，缓存仍有上限；清空只清空当前视口，不删服务日志或用户文件。正则忽略大小写，在独立 Worker 执行，超过 150ms 终止过滤器，需修改表达式后继续。日志支持级别、时间差、长行/堆栈折叠及前后五行上下文，不提供导出或复制按钮。

离开页面会关闭 SSE 和定时器，任务继续在服务端运行；重新进入可从任务记录查看/停止。日志中断时刷新任务状态并提供重新连接，不能把断流当作任务退出。终止先请求进程组退出，五秒未结束才强制停止；真正退出以前仍显示运行中。运行中的任务和日志均不自动写磁盘。

开发验证：`TMPDIR="$PWD/.test-tmp" go test ./...`；`pnpm --dir web build`；`node scripts/check-task-filter.mjs`。后者运行构建后的实际过滤 Worker，验证大小写、无效表达式以及病态正则的线程终止，不代表浏览器页面已验收。
