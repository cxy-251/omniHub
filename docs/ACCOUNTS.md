# 账号管理

管理员在 Web「权限管理」中创建普通用户或管理员、按页查看用户、修改普通用户等级、停用/恢复账号和重置密码。普通用户等级为 0–4，管理员等级固定为 99；角色创建后不通过等级修改隐式转换。停用最后一个有效管理员会返回冲突，不允许锁死管理入口。

已登录账号可通过顶栏「修改密码」提交当前密码与新密码。密码最多 72 个 UTF-8 字节（界面字符数限制不代替服务端字节检查）。修改成功后须重新登录。当前密码验证使用已有登录限速。

停用、重置密码、自行改密、等级变更均撤销账号的全部普通会话与信任设备，网页游戏后续资源请求也会复核身份。恢复账号不恢复旧凭证。账号 ID、媒体状态与历史保留。重复设置相同状态不会额外撤销会话。

数据库增加私有 auth_version，旧库启动时补列而不改变账号及现有会话；密码校验结果仅能在密码、版本、有效状态仍匹配时原子创建会话或执行自行改密，防止并发重置/停用后旧验证结果重新生效。正常身份读取不更新版本、不写访问时间。

接口：

- `GET /api/admin/users?limit=32&offset=0`：有界数组及 `X-Has-More`。
- `POST /api/admin/users/create`：username/password/role/level。
- `POST /api/admin/users/status`：user_id/status（active 或 disabled）。
- `POST /api/admin/users/password`：user_id/password。
- `POST /api/auth/password`：current_password/new_password。

写接口使用服务既有请求体上限与同源保护，新接口拒绝未知 JSON 字段和尾随内容。响应不包含密码哈希和凭证版本；重复用户名返回 409，数据库失败返回 503。

必要验证覆盖真实 SQLite 迁移、最后管理员并发保护、凭证撤销/旧验证竞态、分页与 HTTP 权限/创建/停用/恢复/密码闭环。React 构建通过不代表真实浏览器交互已验收；本阶段未使用浏览器、插件或 Playwright。
