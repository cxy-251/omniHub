# 局域网信任设备

管理员使用账号密码登录后，在 Web“权限管理”中填写名称并点击“信任当前浏览器”。凭证保存在该浏览器的 HttpOnly、SameSite=Strict、host-only Cookie，有效期 180 天；HTTPS 连接同时设置 Secure。仅连接对端属于 RFC1918 IPv4 私有网段（含映射 IPv4）且没有转发头时启用。登记 IP 只用于识别，不作为凭证，DHCP 地址变化后可继续使用。

回环、公网、IPv6 ULA、Cloudflare/反代转发请求均不能使用这份免登录凭证。IPv6 或代理访问可继续通过账号密码登录普通会话。HTTP 局域网访问仍使用 HTTP，信任功能不会自动部署 TLS；当前设备凭证仅适用于你信任的局域网环境。

登记会把当前普通密码会话原子转换为设备凭证：删除该普通会话并清除其 Cookie，防止管理员撤销设备后浏览器又靠旧会话继续登录。其他浏览器的普通会话不受这次转换影响。使用设备凭证时不能继续登记新凭证，需要重新密码登录。

管理页列出名称、账号、登记 IP 和到期时间，支持随时撤销。服务器每个请求重新核对数据库中的有效期、撤销状态及账号当前权限，不缓存管理员身份，也不写“最后访问时间”。设备 Cookie 存在但已失效/不在作用范围时，请求回到 Guest，不回退使用同时提交的旧会话。公开内容仍按 Guest 权限访问，管理操作需要重新验证密码。

重新密码登录会清理当前浏览器的设备凭证；“退出登录”撤销当前普通会话与设备凭证，并清除 Cookie。变更账号等级会撤销该账号的所有普通会话及信任设备。对应网页游戏资源授权一起释放/失效，旧 iframe 不能靠之前的授权继续读取受限内容。

凭证通过密码学随机数生成，数据库只保存 SHA-256 摘要；管理 API 仅返回独立的公开设备 ID，不返回原始凭证或摘要。最多 64 条已登记设备，过期记录仅在显式登记时清理，没有清理定时器或闲置写盘。旧 trusted_devices 表缺少账号/到期信息的历史记录保持未授权，不自动继承管理员权限。数据保存在 users.db，随全局状态主库迁移。

管理页面已迁为 React/TypeScript/Tailwind，保留原有分类分权与用户等级操作。名称始终以文本渲染，不再通过旧管理页的 HTML 字符串拼接展示；页面进入/刷新或修改时读取状态，闲置不轮询。

开发验证使用项目内 SQLite/资源库与模拟 TCP 对端地址：覆盖 RFC1918 边界、映射 IPv4、空/伪造转发头、过期、旧会话禁止兜底、容量与事务失败、撤销/等级变化、重新密码登录、退出及网页游戏资源即时失效。测试确认验证凭证不增加数据库 total_changes。实际多设备浏览器/Wi-Fi/TLS 部署仍需实机验收，模拟对端测试不等同真实网络验收。
